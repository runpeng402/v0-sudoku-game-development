# 数独解题思维训练包规划

## 首版范围

一次性买断 90 道独立训练题。初级、中级、高级各 30 道，另有 9 道免费体验题。每级三个模块，每个模块包含两道引导、四道变式、两道辨析和两道独立检验。

| 难度 | 模块 |
| --- | --- |
| 初级 | 裸单、隐单、区块排除 |
| 中级 | 裸对子与裸三数组、隐性数组、复合推理 |
| 高级 | X-Wing、XY-Wing、综合推理 |

## 样题阶段

- 练习入口为 `/sudoku-practice/lab`，用于本地开发和 Vercel Preview。
- 隐单、裸对子、XY-Wing 各四道，覆盖引导、变式、辨析和独立检验。
- 先寻找依据，再选择操作。删除候选后继续填入新得到的确定数。记录本次页面会话的完成情况。
- 用 `node scripts/verify-sudoku-reasoning.cjs` 验证棋盘唯一解、推理结果和辨析题。题型验证通过后，还要观察试玩者能否在陌生局面独立完成。

## 扩题与上架

训练页现已接入 99 道独立棋盘。访客可从 9 个模块各试做一题，购买确认后服务端开放其余 90 题。使用 `node scripts/verify-sudoku-training-course.cjs` 校验棋盘唯一解、目标推理、辨析选项和连续推理的后续填数。课堂试玩与跨设备学习进度仍待验证。

样题试玩重点观察独立正确率、提示使用和常见误判。审核每题的推理和难度，镜像或换数字的复练题不计入独立题量。付费内容定稿后再更新课程目录、Dodo 商品文案和网站价格入口。价格页与训练页复用邮箱验证及结账接口，购买后的练习进度与跨设备恢复另行验收。
